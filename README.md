# Airsafe MAR Tracker

Internal document-tracking web app for the U-Tapao International Airport Second Runway &
Taxiway project — Airfield Lighting, Section 28 01 00. Replaces the Airsafe MAR tracking
spreadsheet with a live, linked, click-to-tick interface.

See [`CLAUDE.md`](./CLAUDE.md) for the full project brief, domain rules, and data model — it is
the source of truth for this app.

## Scripts

```bash
npm run dev        # start the dev server
npm run build       # typecheck + production build
npm run test        # run the test suite once
npm run test:watch  # run tests in watch mode
npm run lint         # eslint
npm run format       # prettier --write
```
